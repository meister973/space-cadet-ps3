3D Pinball Space Cadet for PS3

You need the files of 3D Pinball from Windows XP: PINBALL.DAT and the SOUND*.WAV files.
They are in C:\Program Files\Windows NT\Pinball on Windows XP.

1. Copy make_spacecadet_pkg.bat and the spacecadet_pkg_files folder into your Pinball folder.
2. Double-click make_spacecadet_pkg.bat.
3. Copy SpaceCadet.pkg to a USB stick.
4. On a PS3 with CFW or PS3HEN, install it with Package Manager, Install Package Files.

The package contains your game files. Do not share it.

Optional music: convert PINBALL.MID to PINBALL.ogg and put it in the Pinball folder before step 2.

The Full Tilt! table also works: use its CADET folder instead of the Pinball folder.

Controls: L1 or L2 left flipper. R1 or R2 right flipper. Cross plunger.
D-pad nudges the table. Start pauses. Select starts a new game.
